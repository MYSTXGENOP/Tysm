# Tysm GitHub source package

This archive is a sanitized copy of the GitHub Updater Build Kit. It excludes user memory, conversation history, local databases, Spotify configuration, playlist preferences, and ntfy topic configuration. It sets `GITHUB_REPOSITORY` to `MYSTXGENOP/Tysm`.

**Do not upload the original ZIP to a public repository.** Inspect any new files before committing, especially for credentials, private data and personal conversations.

The GitHub repository contains source files. For updates, build the installer locally and attach `Tysm_Setup.exe` and `Tysm_Setup.exe.sha256` to a GitHub Release with a version tag such as `v1.1.0`.

The logs feature is not yet implemented in this source package.
